My Works

A central location for quick access to my published works, of any nature. This page is intended to provide access to each work rather than detailed documentation.

All of my programs are designed as standalone Windows applications unless otherwise noted.

Personal Deism

A philosophical worldview that affirms an intentional, good Divine reality while leaving individuals free to pursue truth through reason, spiritual insight, and personal reflection. It holds that persons possess intrinsic worth, that sentient beings deserve fundamental freedoms, and that the purpose of personal existence is moral growth.

Babel

A multilingual text-to-speech application. Babel supports English, French, Spanish, and Khmer. It includes a language-learning curriculum organized by grade level and category, and allows users to add their own words and phrases.

Babel 2.0.0

Added a new screen to allow translation to and from multiple languages (not simply the four) with an internet connection.

BirthPersonaReport

Birth Persona Report is a Windows desktop application built with VB.NET, WinForms, and .NET 10. It brings several traditional and interpretive systems together in a tabbed, person-specific report.

DPDR — Definitive Polyhedral Dice Roller

A program to simulate polyhedral dice-rolling.

MathScrabble

A mathematical word-game inspired by Scrabble, designed to teach and practice arithmetic through play.

MathScrabble v1.1.3

Numerous updates to improve gameplay, including an option for increased board size.

MathScrabble v1.1.5

Added highlighting of tiles, with blank tiles having a pale lavender background in the rack or on the board, and tiles used while typing having a gold background. Added Save/Load capability, allowing players to interrupt long games and resume them later with the board restored.

MathScrabble v1.1.6

Corrected Set Players behavior so players can be configured again after a game ends.
