Clinic CaseManager In progress

A Windows multi-user desktop application designed to manage patient records, clinic operations, and case-related billing across multiple clinics and providers.

Built with VB.NET Windows Forms, Clinic CaseManager provides a centralized system for maintaining patient information, tracking cases, managing involved parties, recording body-part information, and organizing billing-related data.

Key Features

  • Multi-Clinic Management: Supports multiple clinics and providers, with clinic-specific access to patient and case records.
  • User Access Control: Provides Administrator, Supervisor, Staff, and Read-Only access levels.
  • Patient and Case Management: Uses sequential patient and case identifiers to maintain consistent record organization.
  • Data Security: Employs AES-256-GCM encryption and Windows DPAPI-protected encryption keys.
  • Audit Trail: Maintains encrypted, sentence-form audit records of significant activity.
  • Record Integrity: Incorporates soft deletion, save detection, and safeguards against conflicting updates.
  • Flexible Deployment: Supports operation from a shared network location or as an independent local installation.
  • Concurrent Access: Uses file locking and retry mechanisms to protect data integrity when multiple users access shared records.

Clinic CaseManager is designed to provide a secure, organized, and flexible approach to clinic and case management, while supporting both centralized multi-user operation and smaller independent installations.
